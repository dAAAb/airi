# AIRI Local 0.2.0 — 桌寵與語意動作

2026-10-08，Apple Silicon Mac 預發行說明草稿。安裝包及原生視覺驗收狀態待發行時填入。

這版讓角色可切換成透明桌寵，並把 LLM 選擇的 ACT 動作接到 VRM 骨架播放器。

## 新增功能

- 角色主畫面的「桌寵模式」：拖曳握把、置頂、滑鼠穿透、麥克風、文字／圖片對話、視角調整及返回一般視窗。
- `⌘⌥P`、AIRI Dock 圖示或原生選單可解除穿透、找回角色。切換模式沿用同一個舞台與對話元件，保留未送出的文字、圖片附件及語音管線。
- VRM 可依 ACT 標記點頭、搖頭、揮手、鞠躬、慶祝，或播放 `dance`／`sway` 兩種短律動。`idle`／`stop` 取消動作。
- 相容 SARC 輸出的 ACT 空白變體，並將控制標記與送往 TTS 的正文分開。
- 桌寵的緊湊對話框保留歷史訊息空間，隱藏重複工具列。
- 修正程序動作的 VRM 0.x／1.0 座標適配，依格式轉換動作四元數的 X、Z 分量；保留角色自身左右骨架名稱，不以 CSS 鏡像代替修正。原生方向視覺驗收另行記錄。
- 修正已測 Ollama 0.35.1／0.40 回報模型 digest 不同造成的辨識問題。既有 Ollama 接受本發行版預先固定的兩種表示；內建 runtime 只接受固定 manifest SHA，仍逐一驗證自有模型 manifest／blobs，不接受未知 digest。[驗證程式](../installer/manager.py)

## 已記錄的模型測試

在固定的合成單輪動作題中，Gemma 4 12B 為 **4／4**、Qwen 3.5 0.8B 為 **2／4**。SARC 台語 12B 的兩題經實際解析器重播後為 **2／2**；這不是台語發音品質分數。

共 10 則原始回答重播，8 則符合題目動作條件，沒有 ACT 控制標記混入 TTS 正文。API 回答、解析器重播與原生畫面驗收是不同階段。原始資料、評分規則和重現命令放在[桌寵與 AI 語意動作教學](../DESKTOP-PET.zh-TW.md)。

## 使用範圍與限制

- 適用 Apple Silicon。仍是 ad-hoc 簽署，沒有 Developer ID 簽署或 Apple notarization。
- 桌寵需要本機 Mac App；一般瀏覽器網頁不會變成透明桌面視窗。
- 滑鼠穿透作用於整個視窗，尚無逐像素命中測試。重新啟動會關閉穿透。
- LLM 選擇有限的動作名稱；舞蹈是本機預先編排的程序骨架動作，沒有新增神經 text-to-motion 模型、任意舞種或音樂節拍分析。
- 小模型仍會選錯動作或答非所問。不同 VRM 的骨架、衣服和比例會影響表現；臉部／姿態追蹤啟用時，語意骨架動作會讓位。
- Lite 使用 Qwen、Breeze ASR 與 Kokoro：可做台語辨識，Kokoro 的輸出仍為中文聲線。Full 才包含 SARC 及台語 TTS 組合；本次動作測試不等於已重新驗證真人台語收音與發音。
- App 使用獨立的本機 Ollama 服務，不取代原有 `11434`。Lite／Full 沿用離線限制，模型缺漏不會改走雲端。

模型授權與建置方式：[課程 App 說明](README.zh-TW.md)、[模型授權](../installer/MODEL-LICENSES.zh-TW.md)。
